# Practical 5: Pointers and user input

This practical generates the Fibonacci sequence using pointers and compares a series approximation of the inverse hyperbolic tangent with its logarithmic expression.

## Compile and run

Open a terminal in the `practical5` directory.

### fibonacci.c

```bash
gcc fibonacci.c -o fibonacci
./fibonacci
```

### arctanh.c

```bash
gcc arctanh.c -o arctanh -lm
./arctanh
```

Enter the requested Fibonacci index or series tolerance when prompted.
